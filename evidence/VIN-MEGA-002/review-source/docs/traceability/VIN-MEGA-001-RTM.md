## Scope boundary

The existing `Documents`, `Revisions`, and `Files` endpoints are preserved as OpenAPI Candidate material for `VIN-MEGA-002 - Document-to-Decision Workflow`. They are not implementation claims or Mega-001 acceptance evidence.

## Verification interpretation

The automated layer consists of `packages/contracts/test/contract.test.ts`, `packages/domain/test/domain.test.ts`, `apps/api/test/security.test.ts`, and `apps/api/test/api.test.ts`. The API foundation suite covers liveness/readiness, correlation-ID normalization, and a safe dependency-error response; it does not exercise the Mega-001 platform command surface. Platform/API behavioral proof is therefore **UNVERIFIED** wherever this matrix says so.

`packages/database/test/postgres.integration.test.ts` is deliberately conditional on a real PostgreSQL test database. It is the only listed test path that may prove migrations, database constraints, atomicity, and RLS. Until it has real runtime evidence, those targets are **UNVERIFIED**; unit or mocked tests must not be substituted for that proof.
